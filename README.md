# RUSH//RECORD

Готовая браузерная игра по макету из изображения.

## Запуск
Просто открой `index.html` в браузере.

## Возможности
- Aim Rush на 30 секунд
- Reaction
- Click Economy
- Dodge
- Stack / Memory / Endless как дополнительные режимы
- локальные рекорды через localStorage
- таблица рекордов
- профиль и уровни
- достижения
- ежедневный челлендж
- адаптация под телефон

Для настоящих общих рекордов между игроками нужен сервер/API и база данных.
